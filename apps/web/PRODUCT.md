# Trace Web
<!-- impeccable:product-schema 1 -->
## Platform
web

## Goal

Trace 让多媒体线索、用户表达与逐渐形成的理解接续起来，并让其中部分方法进入能力及 Agent 协作。完整目标为思考画布、能力库、Agent 协作三大工作区的15组功能，不按现有接口或开源组件能力裁剪。

功能以[核心功能与内容对象](../../../manunl/产品功能与交互方案/核心功能与内容对象.md)为准；视觉/流程以[设计入口](DESIGN.md)导航到的项目正文为准。进度只在[唯一前端任务记录](../../../docs/tasks/trace-frontend-replacement.md)维护。

## 当前实现事实，不是目标范围上限

- 正式入口为 React + TypeScript 三工作区和 Infinite Canvas 实际交互链；能力/内部思考/外部任务、原件/来源、找回/准确版本已有真实行为。仍保留必要旧DOM/深链兼容，不把旧场景当新视觉权威，也不把上述部分链路误报成15组全部完成。
- 同一 canonical matter 在首页、事项、对照及工作现场中接续。原话、来源、用户理解及工作结果不能互相覆盖；材料关联不等于采用，准备/导出也不等于发送、执行或验证。
- 共享纯规则来自固定 `@trace/product-workspace` 包；Browser 使用 origin 内 IndexedDB，本机可走生产 preload/client 与 Product SQLite。保存必须等权威回执，冲突/未知保留草稿并可恢复或导出。 开发候选、分范围验证与实际安装版本只在唯一任务记录核对，不由本入口或Git HEAD推定；明确版本包打开不采用，新接收先只读，更新先比较。草稿冲突可明确选择本地处理，再单独保存，不将hash当身份认证或下载当送达。能力反馈另存事实/解释/范围及准确版本或明确未知，人工保留、修订和停用不会互相冒充；当前手工/讨论/准备链与既有成功返回的实际来源核验已分范围验证，不能以列表hash元信息替代当前原始记录核验；准确引用选择及反馈找回已接同一索引与真实命令，浏览器链已验证，原生/兼容的本批证据看唯一任务；共同思考每段保存自己的准确引用、排除及明确选择的历史原话；任务草稿不随后来画布选区漂移。原生只读实际输入预览不建立运行，新的调用不自动带旧AI回复或全部历史。历史消息未独立记录范围时保留原运行，新调用先接入新草稿明确核对。能力实际进入新运行、失败来源及完整兼容仍待验。
- `/app/demo` 与个人存储隔离，用会话内存重建明确演示内容；个人空间不自动创建示例资料。公开来源摘要不是全文，也不是用户理解。
- 旧 URL、对象身份、返回位置、草稿及桌面原生连接需要持续兼容。新布局/资源合约和正式安装包 Runtime 对齐仍待完成，不能拿当前源码或测试 main 代证安装器。

## Constraints

免费、无新增商业授权；Infinite Canvas 是优先画布源码路线。新组件沿已确认的 Bricolage Grotesque／MiSans、Lucide、Radix 和作用域 CSS，不叠加第二主题或业务 store。素材和源代码的许可分别核验，不默认复制图片、品牌或字体文件。

公开搜索和个人知乎授权是独立边界；未配置/未连接/失败如实展示，用户明确操作才读取或保留。外部 Agent 通过本机桥接，不在普通网页中接触私有凭证；本轮测试不执行真实 Agent、不使用模型 API Key。账号、云同步、公开市场及完整通用 Agent 执行环境不自动加入目标。

原“仅原生HTML/JS/CSS、五套旧页面分别定视觉、必须保留旧背景/鸟/绿色主题”的限制已被用户确认的完整前端重做取代；旧实现仍须兼容数据和真实业务，不须继续复制其视觉。完整功能、异常、Browser/桌面及用户体验验收仍是总任务结束条件。
