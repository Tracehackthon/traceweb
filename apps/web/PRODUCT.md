# Trace Web
<!-- impeccable:product-schema 1 -->
## Platform
同一 Vercel 部署承载产品交互介绍、完整浏览器应用、视频展示路由和最小同源知乎授权接口；本机运行仍可接 SQLite，正式 Web 应用使用 origin 级 IndexedDB。原 Electron 讨论入口保留为 legacy。
## Product Purpose
围绕一件仍在变化的事，留下一点、从真实停点接着想、形成理解、带去用，并让结果回来。核心功能权威正文为 仓库根目录 manunl/产品功能与交互方案/核心功能与内容对象.md。
## Scope
2026-09-15 用户要求把刚完成的产品交互介绍与产品融合：访问 `/` 先理解产品，再由明确入口进入 `/app/demo` 的完整桌面端演示或 `/app` 的个人空间；`/video` 永久保留给视频。默认 web-main.js 按路径拆分资源，产品内部联结首页、在意的事、一件事、找个对照和工作现场。所有产品页面使用同一 canonical matter；刷新/重新打开从已保存状态继续。原表达可以直接找对照，不暗建理解；材料关联和用户明确保存理解是独立动作；工作保留当时快照，结果确认后才修订当前理解。
搜索 / 全部痕迹只按当前已保存内容检索、保留来路和筛选；这不等于联网搜索。`/app` 首页输入区显式提供「知乎」和「Codex 原生 Agent」两个连接状态入口。连接中心将「知乎 / 全网搜索」标为「尚未直连」：当前 Web 不会联网搜索，但允许用户在「找个对照」中手工带入材料；知乎个人资料 OAuth 则按当前环境真实显示「需配置 / 未授权 / 已授权」，且只有用户明确操作才读取少量资料。Codex 同样尚未直连，当前只准备一份可检查、可复制的交接上下文，不会创建 Codex 任务或伪造执行回执。
个人设置提供偏好、保存位置与导出。个人空间不创建示例用户数据；`/app/demo` 始终使用独立 IndexedDB 和合成数据，即使本地开发也不会把演示记录写入个人 SQLite。演示数据通过同一产品命令生成来源、讨论、理解、对照、交接、工作、结果与修订记录，六个动作都有直达入口。旧独立原型仅保留在 legacy.html。
## Constraints
原生 HTML/JS/CSS；本地字体与既有素材，无 CDN。五套页面分别以对应原型为视觉权威；背景、共享鸟、原字体及现用 vendor 已做资源锁，不反复生图或替换为组件库默认风格。原件留 artifacts，runtime 为派生副本。保留用户已有修改与未接入的后续原型产物。
当前可用边界不等于完整商业产品：自动模型回复、联网搜索、外部 Agent 真正执行、Trace 账号和云同步尚未接入；知乎 OAuth 只授权用户资料，必须由 Vercel Secret 和活动页的新回调地址启用。React base shell CSS 随入口静态加载，因此路由资源失败时加载态与错误恢复界面仍保持基础样式。移动端连接能力按钮至少为 44px 触控目标；shell 对话关闭后把焦点恢复到原触发控件。移动端、OS 输入法全矩阵与桌面包装仍需持续验收。没有把本地确认冒充发送/验证成功。出现存储失败保留草稿、显示重试/导出；版本冲突拒绝静默覆盖。
