# Trace Web
<!-- impeccable:product-schema 1 -->
## Platform
同一 Vercel 部署承载产品交互介绍、完整浏览器应用、视频展示路由和最小同源知乎授权接口；本机运行仍可接 SQLite，正式 Web 应用使用 origin 级 IndexedDB。原 Electron 讨论入口保留为 legacy。
## Product Purpose
围绕一件仍在变化的事，留下一点、从真实停点接着想、形成理解、带去用，并让结果回来。核心功能权威正文为 仓库根目录 manunl/产品功能与交互方案/核心功能与内容对象.md。
## Scope
2026-09-15 用户要求把刚完成的产品交互介绍与产品融合：访问 `/` 先理解产品，再由明确入口进入 `/app/demo` 的完整桌面端演示或 `/app` 的个人空间；`/video` 永久保留给视频。默认 web-main.js 按路径拆分资源，产品内部联结首页、在意的事、一件事、找个对照和工作现场。所有产品页面使用同一 canonical matter；刷新/重新打开从已保存状态继续。原表达可以直接找对照，不暗建理解；材料关联和用户明确保存理解是独立动作；工作保留当时快照，结果确认后才修订当前理解。
搜索 / 全部痕迹按真实内容检索、保留来路和筛选。个人设置提供偏好、保存位置与导出，并提供知乎授权状态、发起、断开和用户明确触发的少量资料读取。个人空间不创建示例用户数据；`/app/demo` 使用独立数据库和合成数据，通过同一产品命令生成来源、讨论、理解、对照、交接、工作、结果与修订记录，六个动作都有直达入口。旧独立原型仅保留在 legacy.html。
## Constraints
原生 HTML/JS/CSS；本地字体与既有素材，无 CDN。五套页面分别以对应原型为视觉权威；背景、共享鸟、原字体及现用 vendor 已做资源锁，不反复生图或替换为组件库默认风格。原件留 artifacts，runtime 为派生副本。保留用户已有修改与未接入的后续原型产物。
当前可用边界不等于完整商业产品：自动模型回复、外部 Agent 真正执行、Trace 账号和云同步尚未接入；知乎 OAuth 只授权用户资料，必须由 Vercel Secret 和活动页的新回调地址启用。移动端、OS 输入法全矩阵与桌面包装仍需持续验收。没有把本地确认冒充发送/验证成功。出现存储失败保留草稿、显示重试/导出；版本冲突拒绝静默覆盖。
