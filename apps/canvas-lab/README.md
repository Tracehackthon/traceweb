# Trace 画布验证室

**技术验证，非正式产品。** 一个页面、同一组自产材料，比较 Drawnix／Plait 与 React Flow；不连接 Trace Runtime，不使用私人材料、真实模型、API Key 或生产存储。默认外观不是 Trace 视觉定稿。

## 启动

在本目录运行：

```powershell
npm run dev
```

打开 [Drawnix 样例](http://127.0.0.1:4196/?engine=drawnix) 或 [React Flow 样例](http://127.0.0.1:4196/?engine=reactflow)。只挂载当前候选，切换采用完整导航；两者的测试存储键彼此独立。4196 被占用时明确报错，不杀其他进程或静默换端口。

首次在新机器准备依赖：Node 22、`npm ci --ignore-scripts`。固定依赖见锁文件，已包含自产素材，正常启动无需 Python、FFmpeg 或重生成素材。npm 缓存位于项目证据目录，不修改全局 npm 配置。

## 体验同一条流程

1. 在文字卡写“我的批注”，移动标题区域；原稿保持不变。媒体控件可独立操作，视频／音频按片段定位。
2. 框选材料，或在右侧勾选参考范围；分组、连线、手绘、平移和缩放。Ctrl＋滚轮缩放；平移模式在空白处拖动，媒体控件仍可使用。
3. 打开“返回原出处”，检查图片、媒体起止及 PDF 页码／区域。不可用来源只展示已留片段。
4. 点击“模拟讨论”，核对“本次实际输入”；采纳、改写、暂存和拒绝有不同结果，只有人工接回才新增材料。
5. 撤销／重做作用于画布操作；材料批注与采用状态独立于形状历史。撤销一个放置不等于删除材料，右侧显示“未放在画布 · 放回”，恢复时复用原身份。
6. 刷新或导出／导入样例，核对原件、定位、批注、画布关系与采用状态。无效导入不覆盖当前内容；已有测试存储损坏时暂停自动保存，只有明确重置才覆盖。

## 结构与边界

- `src/model.ts`：材料、原稿、来源、批注、模拟建议与用户采用状态；独立 IndexedDB `trace-canvas-lab-v1`，只包含合成测试资料。
- 两个候选各自管理形状、视口、选择、分组与连线。共享的是材料和验证场景，不是叠在底座之上的第二套相机或选择系统。
- Drawnix 使用原生 Plait 历史、选择、分组、箭头及 Drawnix 手绘插件。富媒体卡是注册的自定义形状，通过原生生命周期承载 HTML，不冒充 Slate 文本对象。
- React Flow 使用原生节点、连接、选择和视口；手绘采集／`perfect-freehand` 路径以及应用级快照撤销是本样例补充，**不是核心库自带白板，也未复制 Pro 示例**。
- 模拟 Agent 返回固定文字，只验证范围和人工回流；这不证明真实模型、外部 Agent 或能力调用已经验证。
- PDF 卡为预先制作的局部，不包含 PDF 摘取器；其区域通过真实 PDF 页尺寸与文本裁切另行核验。

## 来源与局部补丁

Drawnix 只保留官方源码的三个必要包（约 0.48 MB），未引入整个 Nx 工程；原版权与 MIT 文本保留。被测源码提交记录在 `vendor/drawnix/UPSTREAM.json`，不直接使用较旧的 npm `0.4.0-0` 发布包。

仅两个上游文件有局部补丁，完整差异在 `vendor/drawnix/TRACE-LAB.patch`：

1. `drawnix.tsx`：暴露已有 Plait 插件链和关闭默认工具栏的选项，供比较页面共用范围与操作栏；没有改动引擎相机、选择或历史实现。
2. `styles/index.scss`：两条 SCSS 依赖路径适配当前独立目录。

固定版本、发布标签、源码提交、包完整性与许可来源见 `upstream-audit.json`；许可原文在 `licenses/`，说明见 `THIRD_PARTY_NOTICES.md`。上游完整测试集未执行；本地类型检查覆盖样例自有代码，Vite 编译被复用源码，不能代称已验证上游全部工程。

## 重放验证

```powershell
npm run build
npm run verify
npm run verify:fixtures
npm run audit
```

- `verify`：为每个候选建立全新 Chromium 上下文和动态本地端口；真实指针、输入和文件导入，不依赖当前浏览器页面状态。结束关闭测试浏览器与服务。
- `verify:fixtures`：需要 Python＋PyMuPDF；验证 PDF 页尺寸、定位区域、原文及图片尺寸，输出原件渲染。
- `audit`：核对许可证与固定上游、生成可复核补丁、比较本机实施前的正式工程文件基线。网络异常最多重试两次；历史响应缓存在项目证据目录。换机器缺少本机基线时，不能用它宣称正式工程未变。
- `npm run fixtures` 仅在重做合成素材时使用，需要本机 FFmpeg 和 Playwright Chromium；不下载远程素材。重新生成后应重新构建并验证。

证据统一放在 `../../.test-results/canvas-lab/`：`latest.json` 指向最近一次运行，含每项检查、错误、外部请求、50／200 材料测量和截图。测量只针对当前机器、浏览器与小型合成素材；JS 堆不包含完整 DOM、媒体解码器或进程内存，不构成生产容量承诺。
